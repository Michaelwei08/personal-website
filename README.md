# cpwei.qzz.io

Personal website for Chupeng Wei, focused on selected AI, evaluation, and
scientific-software projects.

The site is static HTML and CSS except for isolated, client-side game routes.
It is designed for deployment on Cloudflare Pages with security headers
defined in `_headers`.

Public pages:

- `/` - selected projects, internship direction, resume, and contact
- `/projects` - selected project archive with evidence and next steps
- `/fun` - game hub for playable systems and upcoming titles
- `/resume` - privacy-reviewed public resume
- `/three-body` - interactive reading platform case study
- `/three-body/demo/` - public, pre-generated interactive reading demo
- `/ultimate-tic-tac-toe` - playable game against an on-device search bot
- `/military` - playable concealed Junqi against an information-set bot
- `/heist` - HEIST/32 case study with a replay viewer
- `/clinical-agent` - client-side clinical-agent safety sandbox
- unknown routes - custom not-found page

The site is static HTML and CSS except for four isolated client-side routes:
`/ultimate-tic-tac-toe` and `/military` run on-device game bots, `/heist`
animates a precomputed trace, and `/clinical-agent` runs a synthetic safety
sandbox. Only those routes receive script-capable Content-Security-Policy rules.

`/heist` does not simulate anything. `assets/heist-replays.js` is generated by
`own/fun/heist/scripts/export_replay.py` and is imported as an ES module rather
than fetched, because every route sets `connect-src 'none'`. To refresh it:

```powershell
cd ..\fun\heist; $env:PYTHONPATH="src"; python scripts/export_replay.py --seed 1 --budgets 0,8,16,32,400 --out ..\..\personal_website\assets\heist-replays.js
```
